# 🛡️ JWT Authentication Example – Spring Boot + JJWT

This branch provides a simple working example of implementing **JWT authentication** using **Spring Boot** and **jjwt (0.11.5)**.

## 🚀 Features

- Generate JWT token based on username.
- Secure endpoint that validates the token.
- Token is signed using HMAC-SHA256.
- Example includes basic setup with hardcoded user (no DB required).

---

## 🧰 Requirements

- Java 17+
- Maven
- Spring Boot 3.x
